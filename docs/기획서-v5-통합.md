## 0. 이 문서에 대하여

지금까지 문서가 둘이었다.

| 문서 | 성격 | 문제 |
|---|---|---|
| 기획서 v4 (13절) | 대화 동작·화면·자원관리까지 상세 | 입(TTS)이 Fish Audio |
| 개정 2판 (8절) | 귀/뇌/입/그릇 구조와 수퍼토닉 확정 | 웨이크워드·메뉴바·음악·타이머가 빠짐 |

**v4의 범위 + 개정 2판의 입 선정**이 사용자 확정 사항이다. 이 문서가 둘을 합치고,
그 사이에 실측으로 확인된 사실을 반영한다. **앞으로 이 문서 하나만 본다.**

## 1. 한 줄 요약

> 클로드 채팅으로 하던 일을 음성으로 하는 앱.
> 말로 시키고, 말로 듣고, 말로 전달할 수 없는 결과물은 화면과 파일로 받는다.

**최우선 원칙 — 목소리의 자연스러움 = 지속 사용의 조건**
아무리 기능이 좋아도 목소리가 어색하면 손이 안 간다. 목소리를 1순위에 두고,
그다음에 비용·속도·기능을 맞춘다.

**비용 원칙 — 뇌를 뺀 전부는 무료**
귀와 입은 로컬 오픈소스로 구동한다. 실제 과금은 Claude API 호출뿐이다.
무료 만료가 예정된 서비스에는 의존하지 않는다.

## 2. 확정된 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| **귀 (STT)** | Whisper (로컬) | 한국어 포함 99개 언어, 무료, 정확도 최상급 |

| **보이스** | **M1** | 10종 직접 청취 후 선택 |
| **음향 프리셋** | **자비스** | −1.2반음, 프레즌스 부스트, 짧은 잔향 |
| **말 속도** | **1.35배** | 수퍼토닉 기본 1.05. 대화용으로 상향 |
| **그릇** | Electron + TypeScript + React | macOS 데스크톱 전용 |
| **호출** | 웨이크워드 + 전역 단축키 | 둘 다 유지 |
| **범위** | v4 전체 | 웨이크워드·2단 타이머·메뉴바·음악 덕킹 전부 포함 |

### 이름의 유래

스타크래프트 골리앗의 기동 대사 "Goliath online"에서 왔다. 자비스 계열의
차분한 남성 기계음이 목표 캐릭터다. 부팅 멘트(4.4절)가 여기서 나왔다.

## 3. 실측으로 확인된 사실

추정이 아니라 이 기계에서 직접 잰 값이다. `bench/` 에 스크립트가 있다.

### 3.1 개발 기계

```
Apple M2 · 통합 메모리 8 GB · macOS 26.4.1
Node v22.14.0 · Python 3.14.4
```

데스크톱 등 다른 기계에서도 돌릴 예정이므로, 모델 크기는 설정값으로 둔다.

### 3.2 수퍼토닉 (입)

| 기획서 주장 | 실측 | |
|---|---|---|
| 무료·로컬·오프라인 | PyPI `supertonic` 1.3.1 구동 확인 | ✅ |
| 한국어 포함 31개 언어 | `--lang ko` 동작 | ✅ |
| 약 99M 파라미터 / 400MB | 385 MB (디스크) | ✅ |
| 기본 보이스 10종 | F1~F5, M1~M5 | ✅ |
| MIT 코드 + OpenRAIL-M 가중치 | 확인 | ✅ |
| `serve` OpenAI 호환 엔드포인트 | CLI 도움말 명시 | ✅ |
| **M1 맥에서 초당 1000자 이상** | **19~41자/초** | ⚠️ 미재현 |

```
모델 로드   600~835 ms · RSS 505 MB (피크)
RTF        0.209 ~ 0.290   → 재생보다 3.4~4.8배 빠름
```

**"초당 1000자" 미재현은 문제가 되지 않는다.** 판정 기준은 처리량이 아니라
RTF 이고, 0.29 는 문장 단위 스트리밍에서 재생이 합성을 앞지르지 않는다는 뜻이다.
벤더 수치는 다른 기계·다른 측정 기준으로 보인다.

### 3.3 현재 파이프라인 성능

```
첫 소리까지   577~640 ms   (모델 로드 후 기준)
취소 반응     132 ms
```

기획서 통과 조건이 6초인데 0.6초다. 문장 단위 스트리밍 덕분이다.

### 3.4 Fish Audio 를 뺀 이유 (확정)

1. **무료가 한시 프로모션이다.** 7/24 → 7월말 → 8/31 로 두 번 연장됐고,
   페이지에 "an initial period" 라고 명시돼 있다. 상시 무료 티어는 없다.
2. **유료 전환 시 한국어가 3배 비싸다.** $15 / 1M **UTF-8 바이트** 과금인데
   한글은 글자당 3바이트다.
3. **맥에서 로컬 구동이 안 된다.** S2-Pro 는 4B 파라미터이고 공식 추론 스택이
   SGLang/CUDA 지향이다. Apple Silicon 지원이 문서에 없다.

부수적으로 v4 부록의 라이선스 근거도 갱신됐다 — CC-BY-NC-SA 가 아니라
**Fish Audio Research License** 다 (코드는 Apache).

## 4. 구조

```
┌──────────────────────────────────────────────┐
│ Electron 메인 (TypeScript)                    │
│  메뉴바 상주 · 전역 단축키 · 자동 실행         │
│  Claude API (검색·코드실행·MCP) · 세션 복구    │
└────┬────────────────────────────┬────────────┘
     │ IPC                        │ 줄 단위 JSON (stdio)
┌────┴──────────────┐   ┌─────────┴──────────────┐
│ 렌더러 (React)     │   │ 음성 엔진 (Python)      │
│  대화 UI · 팝오버  │   │  openWakeWord          │
│  음악 재생 + 덕킹  │   │  Whisper (생명주기)     │
│  효과음 합성       │   │  수퍼토닉 + 음향 프리셋 │
└───────────────────┘   └────────────────────────┘
```

### 변경 불가 원칙

1. **오디오는 프로세스 경계를 넘지 않는다.** 마이크 입력과 TTS 출력은 전부
   음성 엔진 안에서 처리한다. 경계를 넘는 것은 짧은 텍스트 JSON뿐이다.
2. **음악은 렌더러가 재생한다.** 덕킹이 UI 상태와 동기화되어야 한다.
3. **음성 엔진은 교체 가능한 부품이다.** `backends.py` 의 인터페이스가 그 경계다.
   입을 갈아끼울 때 `protocol.py` / `protocol.ts` 는 바뀌지 않는다.

`PROTOCOL_VERSION` 이 어긋나면 앱이 기동 시 거부한다. 현재 v2.

## 5. 대화 동작

### 5.1 상태 전이

```
 [비활성] ──토글──> [대기] ──"goliath online"──> [부팅]
     ^                 ^                            │
     └──토글───────────┘                            │
                       │                            v
                       │                      [듣는 중] <──── 단축키
                       │                            │
                  15초 무발화                  1.2초 침묵
                       │                            v
                       │                       [인식 중]
                       │                            │
                       │                            v
                       │                       [작업 중]
                       │                            │
                       │                            v
                       └──────────────────── [말하는 중]
                                                    │
                                    끼어들기 감지 ───┘
```

### 5.2 두 개의 타이머

혼동하기 쉬우므로 명확히 구분한다.

| 타이머 | 시간 | 의미 |
|---|---|---|
| **청취 창** | 15초 | 답한 뒤 웨이크워드 없이 바로 말을 걸 수 있는 시간 |
| **대화 기억** | 15분 | 대기로 돌아간 뒤에도 맥락을 유지하는 시간 |

**왜 나누는가:** 15분 내내 마이크를 열어두면 혼잣말·통화·옆사람 말이 전부
명령으로 들어간다. 청취는 짧게, 기억은 길게 가져간다.

**정지 조건:** 작업 중이거나 말하는 중에는 청취 창 타이머가 돌지 않는다.

### 5.3 끼어들기

말하는 중에도 마이크를 열어두고, 발화가 감지되면 즉시 출력을 중단한다.

| 출력 장치 | 기본값 | 이유 |
|---|---|---|
| 에어팟 | 켬 | 스피커 소리가 마이크로 거의 새지 않는다 |
| 내장 스피커 | 끔 | 자기 목소리를 되듣고 스스로 끊는다 |

**실측 취소 반응 132 ms.** 재생을 2048프레임(≈46ms) 블록으로 나눠 매 블록마다
취소를 확인한다.

### 5.4 비활성 토글

무거운 작업 중에는 인식을 완전히 끈다. 트레이와 전역 단축키 양쪽에서 전환.
비활성 시 **마이크 스트림 자체를 닫는다** — 메뉴바의 주황 점이 사라져야 한다.
모델도 즉시 해제한다.

## 6. 기능 범위

### 6.1 도구

**원칙: 클로드 채팅으로 할 수 있는 것은 전부 할 수 있게 한다.**

| 도구 | 구현 | 단계 |
|---|---|---|
| 웹 검색 | Claude API 서버측 도구 | M4 |
| 코드 실행 | Claude API 서버측 도구 | M4 |
| 파일 생성 | 로컬 (문서 폴더 저장 후 화면 표시) | M4 |
| 파일 첨부 | 로컬 (이미지·PDF·텍스트) | M4 |
| 음악 제어 | 로컬 도구 | M4 |
| 목소리 변경 | 로컬 도구 (10종 중 선택) | M4 |
| Gmail · 캘린더 · 드라이브 | MCP + 구글 OAuth | M5 |

**할 수 없는 것:** Claude 는 이미지를 생성하지 못한다. 읽고 이해할 수는 있다.

### 6.2 음성 출력과 텍스트 출력의 분리

| 내용 | 화면 | 음성 |
|---|---|---|
| 일반 대화 | 전문 | 전문 |
| 코드 | 전문 (문법 강조) | **읽지 않음.** "작성했습니다" |
| 긴 문서·표 | 파일 다운로드 | "파일로 만들어 뒀습니다" |
| 검색 결과 | 요약 + 링크 | 요약만 |
| 목록 | 전문 | 항목 수와 요지 |
| 오류 | 전문 | 짧은 요약 |

**이중 방어:** 시스템 프롬프트에 규칙을 넣되, TTS 입력단에 **후처리 필터**를 둔다.
Claude 가 규칙을 어겨도 음성에서는 제거된다. 프롬프트만으로는 보장되지 않는다.

### 6.3 음악

일반적인 플레이어 수준. 50곡 이하 전제. 재생·정지·다음·이전·볼륨,
재생목록 편집, 시작 곡 지정, 진행 바 탐색. 전부 음성으로도 조작 가능.

**덕킹**

| 상태 | 음악 볼륨 |
|---|---|
| 대기 | 100% |
| 듣는 중 · 인식 중 · 말하는 중 | 20% (0.3초 페이드) |
| 작업 중 | 60% |
| 대화 종료 | 100% 복귀 (0.5초 페이드) |

사용자가 직접 정지시킨 음악은 대화가 끝나도 자동 재생되지 않는다.

### 6.4 만들지 않는 것

시스템 자동화, 스마트홈, 회의록, 모바일 연동, 다중 사용자, 이미지 생성.

## 7. 화면

- **메뉴바 상주.** 깨어날 때 창을 띄우지 않는다 — 개발 중 방해가 된다.
- 아이콘이 상태 표시: 대기 / 듣는 중 / 작업 중 / 말하는 중 / 비활성
- 클릭 시 작은 팝오버로 최근 대화와 재생 중인 곡
- 전체 창은 메뉴에서 명시적으로 열 때만. 좌측 사이드바(대화/재생목록/설정) +
  중앙 대화 스트림. 시각적 중심은 상태 오브.
- 로그인 시 자동 실행. 시작 시 창 없이 메뉴바에만.
- **부팅 멘트**: 맥북을 켜고 앱이 처음 실행될 때 한 번만 "Goliath online".
  이후 웨이크워드로 깨울 때는 짧은 효과음만.

## 8. 음성 처리

### 8.1 구성

| 역할 | 구성 요소 | 비고 |
|---|---|---|
| 웨이크워드 | openWakeWord + "goliath online" 커스텀 | 학습 전까지 `hey_jarvis` |
| 음성 인식 | Whisper | 모델 크기는 실측 후 결정 |
| 음성 합성 | 수퍼토닉 M1 + 자비스 프리셋 | 로컬·무료 |
| 폴백 | macOS 내장 음성 (Yuna) | 수퍼토닉 실패 시 |

### 8.2 음향 프리셋

수퍼토닉은 담백한 목소리를 낸다. 캐릭터는 후처리에서 만든다.
`engine/goliath_engine/audio_fx.py`. 의존성은 numpy 하나뿐이고, 필터는 전부
FFT 기반 영위상이다.

| 프리셋 | 구성 |
|---|---|
| **자비스** (기본) | 럼블 제거 85Hz · 저중역 정리 340Hz −2.5dB · 프레즌스 3.2kHz +3.5dB · 공기감 9kHz +1.5dB · 잔향 140ms 10% |
| **골리앗** | 무전기 대역 300–3400Hz · tanh 새추레이션 · 링 변조 58Hz 10% · 슬랩백 52ms · 노이즈 플로어 |
| 없음 | 정규화만 |

프리셋은 **발화 단위로 지정**할 수 있다. 부팅 멘트만 골리앗으로 거는 식이
가능하다 — 대역 제한은 캐릭터를 살리지만 긴 답변에는 피로하다.

### 8.3 속도와 음높이는 별개다

수퍼토닉에 **음높이 파라미터가 없다.** 그래서 합성 단계에서 `speed` 에
`pitchFactor` 를 곱해 두고 후처리에서 되돌린다 — 길이는 그대로, 음높이만 내려간다.

| 손잡이 | 기본값 | 범위 | 효과 |
|---|---|---|---|
| `speed` | 1.35 | 0.7 ~ 2.0 | 말 속도 |
| `pitchFactor` | 1.07 | 1.0 ~ 1.3 | 음높이 하강 (길이 불변) |
| `fxIntensity` | 1.0 | 0.0 ~ 1.0 | 효과 강도 |
| `steps` | 8 | 5 ~ 12 | 또렷함 (느려짐) |

### 8.4 한국어 인식 보강

**개발 용어 힌트 주입.** Whisper 에 사전 힌트로 자주 쓰는 기술 용어를 넣는다.
"useEffect", "타입스크립트", "리팩터링" 같은 단어의 인식률이 오른다.
설정에서 편집 가능하게 하고 쓰면서 늘려간다.

**언어는 한국어 고정.** 자동 감지는 시도하지 않는다.

### 8.5 환각 방지

Whisper 는 무음·잡음 구간에서 없는 말을 지어낸다. 한국어에서는
"시청해주셔서 감사합니다" 같은 자막 상용구가 특히 자주 나온다.

1. VAD 필터로 무음 구간 제거
2. 발화 길이가 임계 이하면 폐기
3. 알려진 환각 문구 블랙리스트 차단
4. 인식 신뢰도가 낮으면 되묻기

②~④ 는 **인식 전**과 **인식 후**로 나눠 건다. 대부분 소음인 오디오를 Whisper 에
넘기면 온도 폴백이 반복되어 4초 발화에 10.9초가 걸리고, 결과는 어차피 폐기된다.

**실측으로 보정한 값들** (이 수치들은 감으로 정하면 반드시 틀린다)

| 값 | 설정 | 근거 |
|---|---|---|
| VAD 조각 크기 | 640 | 프레임 1280 을 정확히 2 로 나눈다. 기본값 480 은 나누어떨어지지 않아 마지막 조각이 잘리고, `predict` 가 조각 점수를 평균내므로 점수가 낮아진다 |
| VAD 입력 형식 | **int16** | `predict` 가 내부에서 `/32767` 을 한다. 정규화해 넘기면 이중 정규화로 점수가 0.99 → 0.03 이 되어 발화를 한 번도 감지하지 못한다 |
| 히스테리시스 | 최근 3 중 2 | 프레임 하나로 상태가 뒤집히면 소음이 발화 시작을 오발동시킨다 |
| 종료 조건 | 최근 1.2초 창의 발화 밀도 ≤ 1프레임 | "연속 무음"을 요구하면 산발적 오탐 하나가 카운터를 리셋해 1.5초 발화가 8~20초로 늘어난다 |
| 프리롤 | 0.6초, **소비형** | 길게 잡고 비우지 않으면 직전 발화가 되먹여져 지난 말이 다시 인식된다 |
| 최소 발화량 | 0.16초 (2프레임) | **VAD 는 발화 프레임의 56~59% 만 잡는다** — 음절 사이 정지를 무음으로 표시하는 정상 동작이다. 따라서 집계된 발화량은 실제의 약 57% 이며, 0.4초로 잡으면 1초 미만 명령이 전부 폐기된다 |
| 최소 발화 비율 | 0.08 | 앞쪽 소음과 뒤쪽 침묵 1.2초가 분모에 들어가 구조적으로 희석된다 |

**남은 한계:** "정지" 같은 1~2음절 명령은 Whisper 가 환각으로 번뜨린다
(실측: "정지" → "MBC 뉴스 정지인입니다."). 판정이 차단하지만 명령은 수행되지
않는다. 짧은 명령은 용어 힌트에 넣거나 되묻기로 처리한다.

### 8.6 오디오 장치

시스템 기본 장치를 따라간다. 에어팟 착탈 시 자동 전환.

**알려진 제약:** macOS 에서 에어팟을 마이크 입력으로 잡으면 블루투스가 통화
모드로 전환되어 출력 음질이 떨어진다. 웨이크워드 상시 대기는 마이크 상시
사용이므로 에어팟 착용 중 음악이 계속 저음질로 재생된다. **OS 구조상의
제약이라 앱이 우회할 수 없다.**

**완화 옵션 (기본 끔):** "웨이크워드는 내장 마이크로만 대기". 켜면 대기 중에는
내장 마이크를 쓰고 대화 시작 시 전환한다. 전환에 0.5~1초가 걸려 첫 음절을
놓칠 수 있다.

### 8.7 말투 프리셋

| 프리셋 | 예시 |
|---|---|
| 집사 | "말씀하신 파일을 준비해 두었습니다." |
| 실무형 | "완료했습니다. 세 군데 수정했어요." |
| 친구 | "다 했어. 세 군데 고쳤으니까 확인해봐." |
| 냉소 | "됐습니다. 세 군데. 다음엔 미리 확인하시죠." |

말투와 무관하게 유지: 마크다운 기호 금지, 코드 낭독 금지, 도구는 말이 아니라
실제로 실행.

> 목소리 자체(음색)는 8.2 의 음향 프리셋, 말투(어휘·문체)는 시스템 프롬프트다.
> 둘은 독립적으로 조합된다.

## 10. 자원 관리

### 10.1 모델 생명주기

| 조건 | 동작 |
|---|---|
| 앱 시작 | 로드하지 않음 |
| 첫 호출 | 로드 (로딩 효과음으로 안내) |
| 이후 | 상주분 재사용 |
| **유휴 15분** | 해제 |
| 인식 비활성화 | 즉시 해제 |

유휴 판정은 마지막 음성 출력 종료 시점부터. 작업 중·말하는 중이면 정지.

### 10.2 모델 크기

입은 확정됐다 — 수퍼토닉 **505 MB**. 귀도 실측으로 확정했다.

**Whisper 실측** (M2 Air · mlx-whisper · 24.2초 한국어 샘플 · `bench/whisper_bench.py`)

| 모델 | 힌트 없음 CER | 힌트 있음 CER | RTF | |
|---|---|---|---|---|
| small | 19.8% | 2.5% | 0.043 | |
| **medium** | 38.8% | **0.8%** | **0.122** | **채택** |
| large-v3-turbo | 10.7% | 2.5% | 0.080 | |
| large-v3 | 8.3% | 0.8% | **1.812** | 실격 |

**`large-v3` 는 실격이다.** RTF 1.8 — 24초 발화를 인식하는 데 44초가 걸린다.
기획서 초기 안이 이 모델을 기본으로 잡았으나 이 기계에서는 대화가 성립하지 않는다.

**용어 힌트 주입은 옵션이 아니라 필수다.** medium 은 힌트 없이 CER 38.8%,
있으면 0.8% 다. 8.4절이 실측으로 검증됐다.

**RSS 수치는 신뢰할 수 없다.** MLX 가 통합 메모리에 GPU 버퍼를 잡는데 그것이
RSS 에 잡히지 않아, medium 이 small 보다 작게 측정된다. 판정은 RTF 와 CER 로
충분하므로 결론에는 영향이 없다.

**샘플의 한계:** 수퍼토닉으로 만든 합성 음성이라 실제 마이크 입력보다 깨끗하다.
CER 은 낙관적이며 모델 간 비교용이다. 실사용 검증은 통합 테스트에서 한다.

설정 화면에 현재 메모리 사용량과 최근 응답 지연을 실시간 표시한다.

### 10.3 최적화 방침

측정 없는 최적화는 하지 않는다. 계측을 먼저 붙이고 실측 후 병목만 손댄다.

## 11. 데이터와 안정성

### 11.1 세션 복구

**복구 대상:** 크래시, 강제 종료, 시스템 셧다운
**복구 제외:** 사용자가 직접 종료

앱 시작 시 실행 플래그를 세우고 정상 종료 시 지운다. 시작할 때 플래그가 남아
있으면 비정상 종료로 판단한다. 대화는 매 턴 종료 시 디스크에 기록한다.

### 11.2 대화 히스토리

전체 대화는 로컬 보존. Claude 에 보내는 컨텍스트는 최근 분량만 유지한다.
자르는 지점은 도구 호출 짝이 깨지지 않는 경계. **대화는 중단하지 않는다.**

### 11.3 API 키

macOS 키체인에 저장한다. `.env.local` 에 넣으면 앱이 키체인으로 옮기고
평문을 지운다. 네이티브 모듈 없이 `security` CLI 를 쓴다.

| 키 | 발급 | 필요 시점 |
|---|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com | M2 (보유 중) |
| `GOOGLE_CLIENT_ID` / `_SECRET` | Google Cloud Console | M5 |

수퍼토닉과 Whisper 는 키가 필요 없다.

### 11.4 오프라인

Claude API 실패 시 "네트워크가 끊겼습니다"라고 음성으로 알린다.
**웨이크워드·음성 인식·음성 합성·음악 재생은 전부 로컬이라 계속 동작한다.**
