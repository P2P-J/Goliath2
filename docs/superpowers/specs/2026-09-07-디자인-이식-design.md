# 골리앗 디자인 이식 — 설계

작성 2026-09-07 · 시안 `골리앗 Goliath.dc.html` 기준

기획서 v5(`docs/기획서-v5-통합.md`)의 7절 화면 규정을 이 문서가 대체한다.
기능·프로토콜·엔진에 관한 나머지 절은 그대로 유효하다.

---

## 1. 무엇을 하는가

사용자가 만든 시안을 실제 화면으로 옮기고, M0~M4 에서 만든 기능을 그 위에
다시 붙인다. **기능을 새로 만드는 작업이 아니라 이미 도는 기능을 새 화면에
얹는 작업이다** — 예외는 3.3절의 텍스트 입력과 4.4절의 일회성 미리듣기 둘뿐이다.

### 하지 않는 것

- 엔진(귀·입) 변경. `capture.py` · `microphone.py` · `backends.py` 는 건드리지 않는다.
- 뇌 변경. `brain-*.ts` 는 텍스트 입력 경로가 지나갈 뿐 내부는 그대로다.
- 상태 기계 재설계. `state.ts` 의 7상태와 두 타이머는 그대로다.
- M5 커스텀 웨이크워드, M6 자동실행·패키징, M7 구글 커넥터.

## 2. 결정된 것

브레인스토밍에서 사용자가 고른 답이다. 뒤집으려면 이 문서를 먼저 고친다.

| 갈림길 | 결정 | 이유 |
|---|---|---|
| 목소리 탭 "톤" 카드 세 장 | **자비스 / 골리앗 / 없음** | 시안의 "차분함·기본·밝음"은 음높이 조절이고, 자비스·골리앗은 음향 효과다. 이름의 유래이자 10종을 듣고 고른 정체성이라 버리지 않는다. 시안의 카드 형태만 빌린다. |
| 음악 카테고리 칩 | **하위 폴더 이름** | `music.ts` 가 이미 한 겹 깊이까지 훑는다. 분류를 바꾸려면 파일을 옮기면 된다. 폴더 바로 아래 곡은 "기타". |
| 텍스트 입력의 답 | **입력창 옆 스위치로 그때그때 선택** | 안내문이 "조용한 곳"을 전제하지만 늘 그렇지는 않다. |
| 인식 켜기/끄기 | **사이드바 상태 줄을 눌러 토글** | 시안에 단추 자리가 없다. 이미 있는 "● 대기 중" 줄이 스위치가 되면 새 단추가 필요 없다. 메뉴바와 `⌃⇧⌘G` 는 그대로 둔다. |
| 단축키 표기 | **`⌃⌘G` · `⌃⇧⌘G` 유지, 화면 표기를 고침** | 시안의 `⌘⇧G` 는 파인더의 "폴더로 이동"이다. 전역으로 잡으면 파인더가 망가진다. |

### 시안에서 덜어내는 것

- **`--desk` 바탕과 `--shadow`** — 시안이 창을 띄워 보이려고 만든 것이다. 실제로는 창 자체가 그 카드이고 macOS 가 모서리와 그림자를 그린다.
- **그려 넣은 신호등 세 점** — `titleBarStyle: 'hiddenInset'` 으로 진짜가 뜬다. 자리(사이드바 상단 여백)만 비운다.

### 시안에 없어서 새로 그리는 것

시안은 정상 대화만 그렸다. 실제로는 두 가지가 더 나온다. 같은 언어로 그린다.

- **도구 사용** — 가운데 정렬, `--muted` 12px 한 줄
- **오류** — 붉은 기 도는 카드, 가운데 정렬

### 시안에 있지만 지금 코드에 없어 사라지는 것

- 상태 오브 92px → 사이드바 점 + 우상단 알약 + 마이크 패널이 대신한다
- 덕킹 표시("음악 20%") → 없앤다. 덕킹은 계속 동작하되 화면에 숫자로 알리지 않는다

### 3.1 상태 표시

상태는 일곱이다. 사이드바 점·우상단 알약·마이크 패널이 **같은 문구**를 쓴다.

| 상태 | 문구 | 파형 |
|---|---|---|
| `inactive` | 꺼짐 | 정지 |
| `idle` | 대기 중 | 정지 |
| `booting` | 기동 중 | 정지 |
| `listening` | 듣는 중 | **움직임** |
| `transcribing` | 알아듣는 중 | 정지 |
| `working` | 생각 중 | 정지 |
| `speaking` | 말하는 중 | **움직임** |

**우상단 알약** padding 6/12, radius 999, `--soft` 바탕, `--accent` 글자, 점 6px.

**파형은 장식이다.** 막대 12개, 폭 3px, 높이 `[10,18,14,20,12,16,9,15,11,19,13,17]`,
`wv ${0.7 + (i%4)*0.12}s ease-in-out ${i*0.06}s infinite`.
실제 음량이 아니다 — 오디오는 프로세스 경계를 넘지 않는다(원칙 1). 레벨을 받으려면
새 이벤트를 뚫어야 하는데 시안의 파형도 고정 높이 애니메이션이라 뚫을 이유가 없다.

### 3.2 대화

- 목록 padding 26/26/8, 간격 16px, 각 항목 `fadeUp`
- 말풍선 최대 74%, padding 12/16, radius 16, 14.5px/1.62
- **방향이 지금과 반대다.** 골리앗 = `--accent` 바탕에 흰 글자, **왼쪽**. 나 = `--bubble` 바탕, 오른쪽
- 말풍선 위 라벨 `나` / `골리앗`, 11.5px `--muted`
- 생각 중 = 점 3개, `wv` 를 0/0.15/0.3초 지연으로
- **도구 사용** 가운데 한 줄 `--muted`. **오류** 붉은 카드

**마이크 패널** — 하단, padding 14/18, radius 16, `--panel` 바탕 + `--line` 테두리

- 마이크 단추 44px 원. 듣는 중이면 `--accent` 바탕에 흰 아이콘, 아니면 `--card` 바탕에 `--muted`
- **누르면 듣기 시작 / 다시 누르면 중지** — `⌃⌘G` 와 같은 동작
- 우측 안내 12.5px: 듣는 중이면 `다시 누르면 중지`, 아니면 `⌃⌘G 로 바로 말하기`

**텍스트 입력** — radius 999, padding 6/6/6/18, `--card` 바탕

- placeholder `조용한 곳에서는 텍스트로 입력하세요`
- **소리 스위치** — 켜면 답을 목소리로도 낸다. 끄면 화면에만. localStorage 로 기억
- 보내기 단추 34px 원, `--accent`

### 3.3 음악

- 헤더 = `음악` + 폴더 경로(monospace 12.5px `--muted`) + `폴더 변경`
- **칩** `전체` + 하위 폴더 이름들 + (폴더 바로 아래 곡이 있으면) `기타`.

### 3.4 목소리

- 헤더 = `목소리` + 우측 안내 `고르면 대화 탭에 바로 적용됩니다`
- **기본 보이스** 5×2 격자, 간격 12px. 카드 padding 14/12, radius 14, 테두리 1.5px.
  선택 시 테두리와 글자가 `--accent`
  - 좌상단 id 15px/700, 우상단 **▶ 미리듣기** 24px 원 (`--soft` 바탕, `--accent`)
  - 아래 설명 12px `--muted`. 시안의 문구를 그대로 쓴다

    | | | | | |
    |---|---|---|---|---|
    | M1 낮고 차분한 남성 | M2 밝고 가벼운 남성 | M3 또렷한 뉴스톤 | M4 느긋한 저음 | M5 젊고 빠른 톤 |
    | F1 부드러운 여성 | F2 맑고 또렷한 여성 | F3 낮고 안정된 톤 | F4 친근한 대화체 | F5 차분한 낭독체 |

  - 격자 아래 한 줄로 미리듣기 안내(`previewNote`)
- **말하기 속도** padding 20, radius 16, `--panel` 카드. 0.7~2.0, step 0.05.
  우측에 `1.35×` monospace `--accent`. 아래 양끝 `0.7× 느리게` / `2.0× 빠르게`
- **톤** 3장 가로. padding 14/16, radius 13, 테두리 1.5px
  - `자비스` — 맑고 가벼운 금속성. 기본값
  - `골리앗` — 낮고 무거운 기계음
  - `없음` — 가공하지 않은 원래 목소리
- **음높이 슬라이더는 없앤다.** 시안에 없다. 대신 **프리셋이 음높이를 데리고 다닌다** —
  톤을 고르면 `pitchFactor` 가 함께 바뀐다.

  | 프리셋 | pitchFactor |
  |---|---|
  | 자비스 | 1.07 |
  | 골리앗 | 1.14 |
  | 없음 | 1.00 |

  새로 정한 값이 아니다. `bench/make_voice_samples.py` 의 `PITCH` 에 이미 있고,
  사용자가 10종을 듣고 자비스·M1 을 고를 때 들은 것이 이 값이다.
  `protocol.ts` 에 `PRESET_PITCH` 로 옮겨 화면과 벤치가 같은 값을 보게 한다.

## 4. 코드 구조

### 4.1 렌더러를 나눈다

지금 `App.tsx` 한 파일이 세 화면 + 스타일 + IPC 배선을 전부 지고 있다(530줄).
시안이 화면을 셋으로 뚜렷이 가르므로 그대로 나눈다.

```
src/renderer/
  theme.ts                토큰 · 라이트/다크 · localStorage
  components/
    Sidebar.tsx           로고 · 상태줄(인식 토글) · 탭 · 단축키 · 테마
    StatusPill.tsx        우상단 알약
    Waveform.tsx          막대 12개
    MicPanel.tsx          마이크 단추 + 상태 + 파형 + 안내
  screens/
    Chat.tsx              말풍선 · 생각 중 · 도구 · 오류 · 마이크 패널 · 입력창
    Music.tsx             칩 · 카드 격자 · 하단 플레이어
    Voice.tsx             보이스 10 · 속도 · 톤
  App.tsx                 껍데기와 IPC 배선만
  music.ts  sounds.ts     그대로
```

각 조각은 **props 로만 소통한다.** `window.goliath` 를 직접 부르는 곳은 `App.tsx`
한 곳으로 모은다 — 화면 조각을 따로 열어보고 고칠 수 있어야 한다.

### 4.2 메인·프로토콜에 더할 것

- `protocol.ts`
  - `PROTOCOL_VERSION` **3 → 4** (4.4절 때문)
  - `VOICES` 에 설명 문구 추가
  - `PRESETS` 문구를 위 3.4절대로
  - `PRESET_PITCH` 추가 — 3.4절 표. `bench/make_voice_samples.py` 는 이 값을 가져다 쓴다
  - `speak` 명령에 일회성 지정 추가 (4.4절)
- `protocol.py` 를 같은 값으로 맞춘다. **한쪽만 고치면 기동 시 버전 불일치로 거부된다.**
- `index.ts` — 텍스트 입력 IPC, 미리듣기에 목소리 지정 얹기
- **`music.ts` 는 `Track` 에 `category` 를 더한다** — 하위 폴더 이름, 없으면 `기타`

### 4.3 텍스트 입력

```
렌더러 입력창 → IPC goliath:ask-text {text, speak}
              → turnChain.then(() => handleUserTurn(text, {speak}))
```

`handleUserTurn` 에 `speak` 옵션을 더한다. `false` 면 문장을 엔진으로 보내지 않고
화면에만 흘린다. **뇌·필터·스트리밍 경로는 음성과 완전히 같다** — 다른 것은
`speak()` 를 부르느냐 마느냐뿐이다.

`speak:false` 로 답이 끝나면 발화가 없으므로 `spoken === 0` 경로를 타고
청취 창이 열린다. 이것이 맞다 — 글로 물었어도 이어서 말로 물을 수 있어야 한다.

### 4.4 카드마다 미리듣기 (프로토콜 4)

지금은 `config.set` 으로 설정을 바꿔야만 그 목소리로 말한다. 그러면 **F3 을
들어보는 순간 목소리가 F3 으로 바뀐다.** 고르지 않고 들어만 볼 수 있어야 한다.

`speak` 명령에 일회성 지정을 더한다.

```ts
{ type: 'speak'; id: string; text: string; queue?: boolean;
  voice?: string; preset?: VoicePreset; speed?: number }
```

엔진 `_speech_request(text, overrides)` 가 있으면 그 값을, 없으면 `self.config` 를
쓴다. **설정은 건드리지 않는다.**

미리듣기는 이미 `preview:` 접두사로 대화 상태를 비켜 가고 있다. 그대로 쓴다.

## 5. 검증

단계마다 아래를 전부 통과해야 다음으로 간다.

1. `npx tsc --noEmit`
2. `npm run build`
3. `engine/.venv/bin/python -m compileall -q engine/goliath_engine`
4. **앱이 뜨고 엔진 핸드셰이크까지 간다** — 로그에 `대기 시작` 이 찍힌다
5. 그 단계에서 만든 화면을 눈으로 확인한다

프로토콜을 4로 올리는 단계에서는 **버전 불일치가 나지 않는 것**을 반드시 확인한다.
`protocol.ts` 와 `protocol.py` 중 한쪽만 고치면 엔진이 기동 직후 거부된다.

마지막에 실측할 것:

- 미리듣기로 F3 을 들은 뒤 **설정이 그대로 M1 인지**
- 텍스트로 물었을 때 스위치 끄면 소리가 안 나고, 켜면 나는지
- 라이트/다크를 오가도 색이 남거나 튀지 않는지
- 하위 폴더가 칩으로 잡히고 칩을 누르면 걸러지는지
- 톤을 골리앗으로 바꾸면 `pitchFactor` 가 1.14 로 따라 바뀌는지

## 6. 단계

각 단계 끝에서 앱이 돌고, 5절 검증을 통과하고, 커밋한다.

| | 내용 | 끝났다고 말할 수 있는 조건 |
|---|---|---|
| 1 | `theme.ts` · 사이드바 · 헤더 · 테마 토글 | 라이트/다크가 오가고 탭 이름이 대화·음악·목소리다. 상태 줄을 누르면 인식이 꺼진다 |
| 2 | 대화 화면 · 마이크 패널 · 텍스트 입력 | 말풍선 방향이 시안대로다. 마이크 단추로 듣기가 시작된다. 글로 물어 답이 온다 |
| 3 | 음악 화면 | 칩이 하위 폴더로 만들어지고, 카드에 색·첫 글자·재생 시간이 나온다 |
| 4 | 목소리 화면 · 프로토콜 4 | 카드마다 미리듣기가 되고, 들어도 설정이 안 바뀐다 |
| 5 | 배선 점검 · 실측 | 5절 마지막 네 항목을 전부 확인했다 |
