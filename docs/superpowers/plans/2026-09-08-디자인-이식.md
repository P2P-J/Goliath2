# 골리앗 디자인 이식 실행 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 시안 `골리앗 Goliath.dc.html` 을 실제 화면으로 옮기고 M0~M4 의 기능을 그 위에 다시 붙인다.

**Architecture:** 렌더러를 `theme.ts`(토큰) + `components/`(공통 조각) + `screens/`(화면 3개)로 나누고, `App.tsx` 는 껍데기와 IPC 배선만 진다. 화면 조각은 props 로만 소통하며 `window.goliath` 를 직접 부르지 않는다. 메인·엔진은 텍스트 입력 경로와 `speak` 일회성 지정(프로토콜 4)만 늘어난다.

**Tech Stack:** Electron 43 · React 19 · TypeScript(strict, `noUncheckedIndexedAccess`) · Vite 7 · vitest(신규) · Python 엔진(수퍼토닉/mlx-whisper)

**설계 문서:** `docs/superpowers/specs/2026-09-07-디자인-이식-design.md`

## 먼저 알아야 할 것

### 이 계획을 짜다 실측으로 드러난 결함 2건

M4 음악은 **한 번도 소리가 난 적이 없다.** 사용자가 아직 시험하지 않아 드러나지 않았을 뿐이다.

1. **CSP 가 음악을 통째로 막는다.** `src/renderer/index.html` 의 `default-src 'self'` 가
   `media-src` 의 폴백이 되어 `goliath-media://` 오디오를 거부한다.

   ```
   Loading media from 'goliath-media://...' violates ... "default-src 'self'"
   → MediaError code=4 (SRC_NOT_SUPPORTED), readyState=0
   ```

   `MusicPlayer` 의 `error` 처리기가 `if (tracks.length > 1) this.next()` 라서,
   막힌 상태에서는 **모든 곡을 무한히 돌며 실패한다.**

2. **`Content-Length` 가 없어 `duration` 이 `Infinity` 다.** `music.ts` 의
   `protocol.handle` 이 `net.fetch` 결과를 그대로 돌려주는데 길이가 실리지 않는다.

   | 핸들러 | duration |
   |---|---|
   | 지금 (`net.fetch` 그대로) | `Infinity` |
   | `Content-Length` 를 붙이면 | `24.23` |

   그래서 미니 플레이어의 진행바·시간 표시가 늘 `0:00` 이고, `seek()` 는
   `Number.isFinite(duration)` 에 걸려 **아무 일도 하지 않는다.**

Task 1 이 이 둘을 먼저 고친다. 디자인 이식보다 앞선다 — 카드에 재생 시간을 띄우는
Task 7 이 2번 수정에 의존한다.

### 설계 문서에서 한 가지 바꾼다 — 글꼴

설계 문서는 Pretendard 를 CDN 에서 불러온다고 적었다. 그러면 CSP 의 `style-src` 와
`font-src` 를 외부 호스트로 넓혀야 한다. 마이크와 클로드 자격증명을 쥔 앱에서
외부 CSS 를 허용하는 것은 값이 싸지 않고, 인터넷이 없으면 글꼴이 떨어진다.

**npm 패키지로 넣는다.** `npm i pretendard@1.3.9` 뒤 woff2 하나를 Vite 가 자산으로
내보낸다. CSP 를 넓히지 않고, 오프라인에서 동작하고, 저장소에 바이너리를 넣지 않는다.

실측으로 경로를 확인했다 — `/dist/web/variable/woff2/PretendardVariable.woff2` (2,057,688 B).
설계 문서의 `gh/orioncactus/...` 경로는 jsdelivr 에서 403 이다.

```ts
/**
 * 곡 카드 표시용 순수 함수.
 *
 * 음악 파일에는 앨범 그림도 분류도 없다. 있는 것은 파일 이름과 길이뿐이라
 * 화면에 쓸 것을 여기서 만들어 낸다. DOM 을 건드리지 않으므로 테스트가 쉽다.
 */

/**
 * 파일 이름에서 커버 색을 만든다.
 *
 * 채도와 명도를 고정하고 색상만 바꾼다 — 시안의 커버(#dce6fb, #f0e7dc …)가
 * 전부 옅은 파스텔이라 그 범위를 벗어나면 격자가 시끄러워진다.
 * 라이트·다크 어느 쪽에서도 같은 색을 쓴다. 시안의 다크 화면도 그렇다.
 */
export function coverColor(seed: string): string {
  let hash = 0;
  for (let i = 0; i < seed.length; i += 1) {
    hash = (hash * 31 + seed.charCodeAt(i)) >>> 0;
  }
  return `hsl(${hash % 360} 34% 90%)`;
}

/**
 * 초를 분:초로. 길이를 모르면 --:-- .
 *
 * goliath-media 응답에 Content-Length 가 없으면 duration 이 Infinity 로 온다.
 * 그대로 계산하면 NaN:NaN 이 화면에 뜬다.
 */
export function formatDuration(seconds: number): string {
  if (!Number.isFinite(seconds) || seconds <= 0) return '--:--';
  const total = Math.floor(seconds);
  return `${Math.floor(total / 60)}:${String(total % 60).padStart(2, '0')}`;
}
```

`registerHandler` 를 통째로 바꾼다.

```ts
  registerHandler(): void {
    protocol.handle(MUSIC.scheme, async (request) => {
      const target = decodeURIComponent(new URL(request.url).pathname);
      const folder = this.settings.folder;
      // 폴더 밖은 내주지 않는다. 렌더러가 임의 경로를 요청해도 막힌다.
      if (!folder || !resolve(target).startsWith(resolve(folder) + sep)) {
        return new Response('not found', { status: 404 });
      }

      const response = await net.fetch(pathToFileURL(target).toString());
      // 길이를 실어 주지 않으면 <audio> 의 duration 이 Infinity 가 된다.
      // 그러면 재생 시간 표시도, 진행바도, seek 도 전부 죽는다 (실측 확인).
      try {
        const { size } = await stat(target);
        const headers = new Headers(response.headers);
        headers.set('Content-Length', String(size));
        headers.set('Accept-Ranges', 'bytes');
        return new Response(response.body, { status: response.status, headers });
      } catch {
        // 길이를 못 재도 재생 자체는 되게 둔다.
        return response;
      }
    });
  }
```

```ts
 *
 * 글꼴은 CDN 이 아니라 npm 패키지에서 온다. Vite 가 자산으로 내보내므로
 * CSP 를 외부 호스트로 넓히지 않아도 되고 인터넷이 없어도 뜬다.
 */
export function installStyles(): void {
  if (document.getElementById(STYLE_ID)) return;

  const style = document.createElement('style');

  style.textContent = `

  font-style: normal;
  font-display: swap;
}

@keyframes fadeUp { from { opacity: 0; transform: translateY(6px); } to { opacity: 1; transform: none; } }
`;
  document.head.appendChild(style);
}

const KEY = 'goliath:theme';

/** 저장된 테마. 없으면 시안의 기본값인 라이트. */
export function loadTheme(): ThemeName {
  try {
    return localStorage.getItem(KEY) === 'dark' ? 'dark' : 'light';
  } catch {
    // 사생활 보호 모드 등에서 막힐 수 있다. 기본값으로 간다.
    return 'light';
  }
}

/** 테마를 문서에 반영하고 기억한다. */
export function applyTheme(theme: ThemeName): void {
  document.documentElement.dataset.theme = theme;
  try {
    localStorage.setItem(KEY, theme);
  } catch {
    // 기억하지 못해도 이번 실행 동안은 동작해야 한다.
  }
}
```

```ts
import { relative, sep } from 'node:path';

/**
 * 곡의 분류 (기획서 3.3절).
 *
 * 음악 파일에는 분류 정보가 없다. 사용자가 폴더를 나눠 넣은 것을 그대로 쓴다 —
 * `music.ts` 가 이미 한 겹 깊이까지 훑고 있어 공짜다.
 *
 * **electron 을 import 하지 않는다.** 테스트가 node 환경에서 돈다.
 */

/** 폴더 바로 아래에 있는 곡의 분류. */
export const OTHER = '기타';

/** 곡 경로에서 분류를 뽑는다. 하위 폴더 이름, 없으면 '기타'. */
export function categoryOf(trackPath: string, folder: string): string {
  const rel = relative(folder, trackPath);
  // 폴더 밖이면 relative 가 '..' 로 시작한다.
  if (!rel || rel.startsWith('..')) return OTHER;
  const parts = rel.split(sep);
  const first = parts[0];
  return parts.length > 1 && first ? first : OTHER;
}
```

```ts
  /**
   * 재생하지 않고 곡 길이만 읽는다 (카드 표시용).
   *
   * Content-Length 가 실려야 duration 이 나온다 — music.ts 의 프로토콜
   * 핸들러가 붙여 준다. 없으면 Infinity 가 오고 화면은 --:-- 를 띄운다.
   */
  static probeDuration(url: string): Promise<number> {
    return new Promise((resolve) => {
      const probe = new Audio();
      const done = (value: number) => {
        probe.src = '';
        resolve(value);
      };
      probe.preload = 'metadata';
      probe.addEventListener('loadedmetadata', () => done(probe.duration));
      probe.addEventListener('error', () => done(0));
      // 응답이 없으면 영원히 매달리지 않는다.
      setTimeout(() => done(0), 5_000);
      probe.src = url;
    });
  }
```

```ts
/** 폴더 바로 아래에 있는 곡의 분류. main/track-category.ts 의 OTHER 와 같은 값이다. */
const OTHER = '기타';

/**
 * 칩으로 만들 분류 목록.
 *
 * 나온 순서를 지키고 '기타'는 맨 뒤로 민다. 분류가 '기타'뿐이면 —
 * 폴더를 안 나눈 경우다 — 빈 배열을 줘서 칩을 아예 그리지 않는다.
 */
export function categoriesOf(categories: string[]): string[] {
  const seen = [...new Set(categories)];
  const named = seen.filter((c) => c !== OTHER);
  if (named.length === 0) return [];
  return seen.includes(OTHER) ? [...named, OTHER] : named;
}
```
